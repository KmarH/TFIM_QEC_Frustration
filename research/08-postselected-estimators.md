# Research Note 08 — Error bars for post-selected (weighted) trajectory estimators

**Sweep note (2026-10-24).** Scope: Monte-Carlo trajectory simulation of an Iceberg-code (error-*detection*) circuit; each trajectory carries a survival weight w ∈ [0,1] (0 once a detector fires), readouts are exact, so the only randomness is over trajectories grouped into B independent batches. Q1 Kish ESS source and "too small" thresholds; Q2 variance of a post-selected (ratio) mean; Q3 jackknife / bootstrap / batch means and the minimum number of batches; Q4 small-count binomial intervals; Q5 how QED experiments report error bars and discard rates; Q6 overconfident error bars under weight collapse.
- **Q1.** ESS = (Σw)²/Σw² is Owen eq. (9.13) [S3]; equal to n/(1+cv²) (9.15) [S3], which is Kish's 1+relvar(w) design effect [S2→S1]; derived by Kong (1992) via the delta method [S3,S4]. Owen: the point where ESS "becomes alarmingly small is hard to specify … application specific" [S3]; ESS ≥ 1 always, so it cannot flag a useless estimate [S4]. The only stated number is the SMC *resampling trigger* N_T = N/2 [S5], not a reporting floor.
- **Q2.** The post-selected mean Σw f/Σw is a self-normalised / ratio estimator; delta-method variance E[w²(f−μ)²]/(n E[w]²), eq. (9.8)–(9.9) [S3]. Owen writes acceptance–rejection as ΣA_iY_i/ΣA_i (ratio formula (2.29), §2.7) with ~n/c accepted points [S3 §9.5]. For 0/1 weights this gives σ²/(n·acc), the 1/acceptance inflation [derived].
- **Q3.** Jackknife error = √(N−1)·s_J, eq. (52); grouping into N_group bins carries over unchanged; prefer jackknife for error bars, bootstrap for full distributions [S8]. Bins must be uncorrelated; a bootstrap or jackknife is needed on top of binning for nonlinear functions [S9]. Binning error-of-error ≈ √(2B/N) = √(2/N_bins), eq. (46) [S7]. **Batches:** "effects of less than 10 batches are large and … more than 30 batches small" [S10]. Blocking: [S11].
- **Q4.** For small n, Wilson or equal-tailed Jeffreys; for larger n, Agresti–Coull. Textbook Wald-safety prescriptions "cannot be trusted" [S12]. No np ≥ 5/10 rule was verified in any fetched text.
- **Q5.** Iceberg [S13]: 32 statevector trajectories per circuit with exact discard probabilities; 99 % bootstrap CIs on medians; discard rate plotted next to every result; no acceptance floor. QAOA+Iceberg [S14]: standard errors; post-selection rate reported; a 10 % post-selection contour drawn as a reference, not a rule. 2503.20870 [S15]: all error bars are bootstrap SEs (100–200 resamples) with the full pipeline re-run per resample; plain post-selection called "not scalable" (exponential overhead). Sparse-QED [S16]: error bars 1/√n_kept; "shot horizon" = time when acceptance falls below **1 %**.
- **Q6.** Weight degeneracy / impoverishment [S5]; the required ensemble grows exponentially with dimension [S6]. Skewed weights give "a bad variance estimate that masks the problem" [S3]; the empirical-variance diagnostic provably declares convergence too early [S17, Thm 2.1]; binning "too small error bars" can fake new physics [S9]. These explain the 3e-17 SE.
- **Gaps:** Kish 1965 book, Kong 1992 TR, Efron–Tibshirani and Flyvbjerg–Petersen text not read. **No source gives a numeric ESS reporting floor.** **Conflicts:** none. [S4] argues ESS is a poor proxy for variance; [S3] uses it as a diagnostic only.

## Recommended pre-declared rules

[derived from the sources above; the floor numbers are conventions, not sourced thresholds]
1. Estimator per time point t: R_t = Σ_i w_it f_it / Σ_i w_it (the ratio/SNIS form [S3]). Report n_kept,t = #{w_it > 0}, the Kish ESS_t = (Σw)²/Σw² [S3 (9.13)] and ESS_σ,t = (Σw²)²/Σw⁴ [S3 (9.16)]. With 0/1 weights ESS equals the survivor count.
2. **Floor:** if ESS_t < 10, report "no estimate", not a number with an error bar. No source gives a number; Owen says it is application-specific [S3], and a variance estimated from the same weights can mask the failure [S3, S17]. The value 10 copies Schmeiser's "<10 batches → large effects" [S10] and the √(2/10) ≈ 45 % error-of-error [S7]: below 10 effective samples the error bar is itself unreliable. The familiar "np ≥ 5/10" rule was **not** found in any fetched source, and S12 warns against such textbook rules. The SMC N/2 rule [S5] is a resampling trigger, not a floor.
3. **Error bar:** delete-one-batch jackknife on the *pooled* ratio, R_(−j) = Σ_{b≠j}N_b / Σ_{b≠j}D_b, with SE = √((B−1)/B · Σ_j (R_(−j) − R̄)²) [S8 (52)]. For the window-averaged residual, form the window average inside each leave-one-out replicate, so correlations between time points pass through automatically: batches are independent, time points are not [derived]. Use B ≥ 10, preferably 20–30 [S10]. A bootstrap over batches is the cross-check [S15 style]. Also require ≥ 10 batches with Σw > 0, otherwise "no estimate".
4. **Shot cost:** with a fixed kept-shot target per circuit instance j, raw shots ∝ mean_j(1/a_j). With an even raw split, kept ∝ mean_j(a_j). By Jensen, mean(1/a) ≥ 1/mean(a), so quote both and state which allocation is meant [derived]. Also report acceptance itself next to every point, as [S13, S14, S16] do. 1 % acceptance [S16] is a published horizon convention, usable as a second flag.
